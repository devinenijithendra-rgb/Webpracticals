## About the Project

This project is a collection of practical programs developed using:

- HTML
- CSS
- JavaScript

The purpose of this project is to practice fundamental web development concepts and create interactive web pages and mini projects.

Each practical program is created as a separate HTML file, as required by the assignment.

---

## Project Objectives

The main objectives of this project are:

- Learn HTML fundamentals.
- Practice CSS styling and layouts.
- Understand JavaScript programming.
- Practice DOM manipulation.
- Understand JavaScript events.
- Create and validate forms.
- Work with browser objects and browser features.
- Learn Web Storage.
- Create interactive JavaScript mini projects.
- Develop responsive and user-friendly web pages.
- Practice organizing a multi-page website.

# Sections

## 1. HTML Programs

The HTML section contains practical programs demonstrating fundamental HTML concepts.

Topics include:

* Basic HTML structure
* Headings and paragraphs
* Lists
* Links
* Images
* Tables
* Forms
* Semantic HTML
* Audio and video
* Iframes
* HTML5 elements

Each HTML practical is stored as a separate HTML file.

---

## 2. CSS Programs

The CSS section demonstrates different styling and layout techniques.

Topics include:

* CSS selectors
* Colors
* Backgrounds
* Text and fonts
* Box model
* Display properties
* Positioning
* Flexbox
* CSS Grid
* Transitions
* Animations
* Responsive web design
* Cards and buttons

Each CSS practical is stored as a separate HTML file.

---

## 3. JavaScript Programs

The JavaScript section is divided into six categories.

### Mini Projects

Examples include:

* Digital Calculator
* Digital Clock
* Stopwatch
* Countdown Timer
* To-Do List

### DOM Manipulation

Examples include:

* Changing HTML text
* Changing element styles
* Creating elements dynamically
* Removing elements
* Creating dynamic lists

### JavaScript Events

Examples include:

* Click events
* Mouse events
* Keyboard events
* Form events

### Forms and Validation

Examples include:

* Registration form
* Login form
* Email validation
* Password validation

### Browser Objects & Features

Examples include:

* Window object
* Location object
* Navigator object
* Date and time

### Web Storage

Examples include:

* Local Storage
* Session Storage
* Storage-based To-Do List
