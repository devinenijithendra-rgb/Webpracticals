This page demonstrates different CSS positioning properties. Scroll down to see how sticky and fixed positioning work.

Static elements remain in the normal document flow. Relative elements can be moved relative to their normal position.

Absolute elements are positioned relative to their nearest positioned parent.

Fixed elements remain in the same position on the screen even when the page is scrolled.

Sticky elements behave like normal elements until a specified position is reached, after which they remain fixed while scrolling.

CSS positioning is useful for creating navigation bars, overlays, floating buttons, and other webpage layouts.
