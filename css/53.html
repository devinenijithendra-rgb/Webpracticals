CSS Visibility and Hiding Elements

1. Visibility: Visible

This element is visible.

2. Visibility: Hidden

This element is hidden.

The hidden element still occupies space on the page.

3. Display: None

This element is completely hidden.

The display:none element does not occupy any space.

4. Opacity: 0

This element is transparent.

The element is still present and occupies space, but it cannot be seen.
