CSS Overflow Properties

Visible

This is an example of overflow: visible. The content that exceeds the size of the box will remain visible outside the box.

Hidden

This is an example of overflow: hidden. Any content that exceeds the size of the box will be clipped and will not be displayed.

Scroll

This is an example of overflow: scroll. Scrollbars are displayed so that the user can view the content that does not fit inside the box.

Auto

This is an example of overflow: auto. Scrollbars appear only when the content exceeds the available space.
