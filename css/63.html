Two-Column Layout Using CSS Grid

About CSS Grid

CSS Grid is a powerful layout system used to create rows and columns on a webpage.

It makes it easy to design responsive layouts. In this example, the main content occupies two parts while the sidebar occupies one part.

Benefits of CSS Grid

CSS Grid provides control over rows, columns, spacing, alignment and responsive webpage layouts.
